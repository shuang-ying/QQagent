# 发行版更新记录

## 2026-10-05

同步当前 Agent 功能，重写首次使用说明，接入说明以 snowluma / 标准 OneBot v11 为主。

- 通用 OneBot 接入：账号/API就绪检查、请求回执、重连、消息去重与兼容入口。
- 会话串行与直接请求优先；短消息合并、过时主动任务取消、投递结果记录。
- 统一主动/被动回复窗口，合并当前、窗口与明确引用的图片；被动回复固定触发者，保留聊天中的稳定QQ与引用关系。
- 九条指令独立权限及后台设置。
- 结构化人格、keep/new切换和历史人格来源记录。
- 人格兴趣/同义表达、当前话题与可信记忆的本地相关性判断。
- 图片资料识别、媒体限制与预算、压缩、事实生命周期、向量检索及后台诊断。
- 同步严格类型检查、离线/隔离回归和专项测试；npm默认测试不使用真实QQ或模型。
- Node最低版本调整为22.16.0，以匹配使用的SQLite事务状态API；建议Node24 LTS。
- 保留发行版无供应商/密钥/个人QQ的通用配置，以及主动发言、表情包等保守默认值。
- 强化Git/npm忽略与文件白名单，发布包排除数据库、日志、私密配置、工具会话与内部联调报告。

运行数据库和日志不是发行内容。已有实例更新时请先停止、备份本地配置和数据，再安装依赖并重启。
