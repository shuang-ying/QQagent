# 语音、人格语音、提醒与群聊日报

## 已实现的功能

| 功能 | 行为和后台入口 |
| --- | --- |
| 语音理解 | 模型用途新增ASR；识别后的文字替换原消息占位符，保留消息ID、作者和所在话题，加入正常聊天、记忆与压缩流程。后台概览的语音设置可启用和选择协议。 |
| 人格语音回复 | 模型用途新增TTS；后台人格编辑可设置独立供应商、模型、音色、语速和朗读风格。正常文字先发送成功，再合成并发送OneBot record消息。 |
| 定时提醒 | 存入SQLite，进程重启后恢复；支持私聊和群聊，群提醒会@创建者。后台“提醒与日报”可创建、查看、取消和检查执行记录。 |
| 群聊日报 | 使用“摘要”用途的模型，只读取目标群最近24小时的已记录用户消息；可手动生成，或每天按应用时区定时发送。 |
| 指令权限 | 新增四项独立权限，沿用管理员／全部／白名单和管理员三种范围；后台权限页可设置。 |
| 调用统计 | ASR/TTS实际请求的成功、失败、耗时写入llm_calls；音频服务通常不返回聊天token用量，此处不估算费用。 |

## 如何配置语音

1. 重启Agent，让程序加载新代码。现有配置文件不需要手动迁移。
2. 在后台添加或选择语音供应商，填写Base URL、API Key和必要请求头。可与聊天共用供应商，也可分开；密钥仍由现有凭据配置处理。
3. 在“模型用途”分别为“语音识别”和“语音合成”选择供应商、模型。供应商可继承默认，**语音模型必须明确指定，不继承聊天模型**。模型列表没有暴露语音模型时，可在旁边手填模型ID并保存。
4. 在概览的“语音”设置中选择ASR/TTS协议。`auto`根据供应商协议选择Gemini或OpenAI兼容；Anthropic、Ollama供应商需要另选语音服务或配置自定义HTTP，不能直接视为支持语音。
5. QQ录音常为SILK。程序会调用OneBot v11 `get_record`请求WAV转换；如果返回本地文件，在“可信语音目录”加入实际转换缓存目录的绝对路径。只授权需要的目录；HTTP音频、base64音频无需本地目录配置。snowluma是否支持转换与发送语音需以实际运行版本为准。
6. 启用“语音理解”“人格语音回复”。TTS默认`on-audio`，只在回复窗口含录音时附加语音；`always`会为普通主动、被动模型回复都附加语音。人格编辑中的语音开关可单独禁用。

识别和合成默认关闭，定时提醒默认开启，群聊日报默认关闭。语音转写**不会作为管理指令执行，也不会直接创建提醒**；定时任务通过文字指令或明确的文字提醒语句创建。人格朗读风格、语速需要服务端支持对应参数；Gemini原生只使用音色与朗读提示，不发送OpenAI的speed参数。

可优先考虑以下接口组合，具体可用模型、音色和计费以服务商当前文档及账号权限为准：

| 服务 | ASR示例 | TTS示例 | 适配方式 |
| --- | --- | --- | --- |
| OpenAI | `gpt-4o-mini-transcribe` | `gpt-4o-mini-tts`，音色如`coral` | OpenAI兼容；官方[识别说明](https://developers.openai.com/api/docs/guides/speech-to-text)、[合成说明](https://developers.openai.com/api/docs/guides/text-to-speech) |
| 硅基流动 | `FunAudioLLM/SenseVoiceSmall` | `FunAudioLLM/CosyVoice2-0.5B`，音色ID如`FunAudioLLM/CosyVoice2-0.5B:alex` | OpenAI兼容；中文语音可先评估这组，参考[ASR接口](https://docs.siliconflow.cn/docs/api/audio-transcriptions-post)、[TTS能力](https://docs.siliconflow.cn/docs/userguide/capabilities/text-to-speech)。若不支持instructions，可把TTS风格字段名设为空。 |
| Gemini或自建语音服务 | 选择账号支持音频输入的模型 | 选择支持音频输出的TTS模型和音色 | Gemini原生／自定义HTTP。未调用真实服务，模型能力需按服务端确认。 |

这里的“全类型适配”指供应商不限，可选择原生或通用HTTP适配。需要专用签名算法、WebSocket实时协议或异步轮询的服务，应通过自建HTTP网关接入；不承诺任意私有协议无需适配即可运行。

## 自定义HTTP配置

ASR支持multipart文件上传或base64 JSON；TTS支持二进制音频、JSON base64、JSON音频URL响应。端点路径默认相对于供应商Base URL，也可填写绝对HTTP URL；认证信息会发送到所填端点，音频URL下载不携带供应商密钥。

请求字段可重命名，留空则省略；响应字段支持点路径，如`data.transcript`、`result.audio`。额外请求JSON支持嵌套模板，整段字符串等于以下变量时会替换：`$model`、`$audioBase64`、`$mimeType`、`$text`、`$voice`、`$speed`、`$instructions`、`$format`。不执行表达式或脚本。

例如自定义ASR，选择`custom`、`base64-json`，把模型字段、文件字段设为空，响应路径填`result.transcript`，额外请求JSON填：

```json
{"request":{"engine":"$model","audio":"$audioBase64","mime":"$mimeType"}}
```

自定义TTS，选择`custom`，将默认平铺字段设为空，按服务端格式填写额外请求JSON：

```json
{"request":{"text":"$text","speaker":"$voice","rate":"$speed"}}
```

若服务返回`{"data":{"audio":"...base64..."}}`，响应形式选择`base64`，响应路径填`data.audio`。供应商不接受某个默认字段时，务必将其字段名设为空。不要在额外请求JSON里放密钥。

## 提醒与日报指令

| 指令或语句 | 用途 |
| --- | --- |
| `/remind 10m 喝水` 或 `/提醒 10分钟 喝水` | 相对时间提醒，支持秒／分钟／小时／天及s/m/h/d |
| `/remind 明天09:00 开会` | 应用时区下的指定时间提醒 |
| `/remind 2026-10-10 09:30 开会` | 指定日期时间提醒 |
| `10分钟后提醒我喝水`、`明天9点提醒我开会` | 私聊可直接发送；群内需@机器人。只接受明确的提醒语法，不由模型自行创建任务。 |
| `/reminders` 或 `/提醒列表` | 当前会话自己的待执行／执行中／结果未知任务，管理员可看当前会话所有人的任务 |
| `/cancelremind 完整任务ID` 或 `/取消提醒 完整任务ID` | 取消自己的当前会话任务；管理员可取消当前会话其他人的任务。正在执行的任务不允许取消。 |
| `/daily` 或 `/日报` | 在当前群生成最近24小时日报 |
| `/daily at 21:00` 或 `/日报 at 21:00` | 每天定时发送日报；仅管理员可设置，且必须先在后台启用日报 |

日报只知道bot已记录的内容，不自动拉取离线期间QQ历史。最多读取最新500条，文字预算12000字符，优先保留最新消息并按时间顺序总结；录音使用已有转写，图片仅使用已记录的文字描述，不为日报额外调用识图。覆盖量会显示在日报开头。每个群只允许一个待执行定时日报。

## 运行约束与数据保留

- 任务创建、发送前都核验当前用户／群准入，白名单变化可阻止投递。后台任务接口受现有Web鉴权保护。
- 默认每个用户最多20个待执行任务，提醒最短1秒、最远365天；断线期间不发送，恢复后只补发默认24小时宽限内的任务。
- 已确认失败的提醒最多尝试3次，间隔60秒；超时、断线后无法确认投递或缺少可靠消息ID时标记`unknown`，不自动重复发送。进程异常退出的旧执行中任务也按未知结果处理。
- 日报成功或已知失败后推进下次日期，结果未知时暂停；关闭功能会暂停待执行任务，过期规则在再次启用时生效。
- 默认语音超时30秒、音频最大20MB、最多4个并发任务，每条消息最多处理2段录音。合成文本默认最多1500字，发送还受OneBot缓冲上限限制；超限保留文字。
- 转写失败明确标为未能转写，不猜测录音；识别中切换话题会取消旧任务。文字投递成功后才尝试语音；语音失败保留已发送文字，语音投递不会自动重发。
- 数据库版本升为v5，仅新增任务与执行记录表。下次实际启动时先创建`pre-v5`数据库备份再迁移；升级时保留自己的数据库。
- 升级时保留自己的配置、人格、数据库、日志与`.env`。新字段缺省值由兼容Schema提供，后台保存时才写入文件。


## 验证

`npm run test:speech`运行24项语音检查，`npm run test:scheduled-tasks`运行23项定时任务检查。均使用本地模拟服务和隔离数据库；真实供应商与OneBot语音能力需要按自己的环境联调。
