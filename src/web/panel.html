提示

· 黑名单优先级最高：在黑名单里的 QQ 一律不处理（连命令也不响应）。
· 白名单非空即启用：用户白名单限制普通聊天，指令按各自权限判定；管理员可使用授权指令。
· 群白名单只影响群聊，私聊不受影响。
· 开启「仅管理员」前请先填管理员 QQ，否则没人能用这些命令 —— 面板会拦下这种配置。
· 提示词注入无法 100% 杜绝，最有效的还是控制机器人进哪些群。

库状态

关于「自动发送」

两条路都开着，可以各自开关（在「概览 → 功能开关 → 回复行为」）：
① 模型自主决定：提示词里带上每张图的标签和描述，模型觉得该发时会在正文末尾写 [表情:标签]，正文照常发，然后单独发一条图。
② 自动发送：开启后，模型点名和自动补图统一受情绪强度、冷却和概率限制，每轮只判定一次概率。 模型没写标记时，结合回复内容和已识别情绪挑选图片；用户明确要求发表情包时直接满足。
建议：先只开 ①，观察一阵再考虑开 ②；② 的冷却别低于 120 秒。

GitHub 动态追踪

      
支持两种模式：追踪一个或多个 GitHub 作者的公开动态，或订阅指定仓库（按分支比对 HEAD SHA、跟踪 Release）。两种模式都推送到本页单独选定的会话；这里的会话与项目里的群/用户白名单互不影响。

追踪设置

        

        

          
          
          
        

        

          · 配置保存在本机 config/github.yaml；含 Token 时不会提交到 Git。

          · 作者动态读 GitHub 公开事件流（有几十秒到几分钟缓存）；追踪作者还会自动订阅其全部公开仓库，仓库订阅直接查 commits / releases，更即时、更可靠。

          · 匿名请求每小时 60 次，填 Token 后 5000 次；首次加入作者或仓库只建立基线，不会把历史动态刷进会话。
